# 🏏 Cricket Scoring Rules - Complete Guide

## ✅ All Cricket Rules Implemented

### 1. **⚾ Regular Deliveries** (Ball Counted)
| Button | Runs | Balls | Description |
|--------|------|-------|-------------|
| Dot Ball | 0 | +1 | No runs scored |
| 1 Run | 1 | +1 | Single run |
| 2 Runs | 2 | +1 | Two runs |
| 3 Runs | 3 | +1 | Three runs |
| 4 (Boundary) | 4 | +1 | Ball reaches boundary |
| 6 (Six) | 6 | +1 | Ball crosses boundary without bouncing |

---

### 2. **🚫 Extras - Wide & No Ball** (NO Ball Counted)
| Button | Runs | Balls | Description |
|--------|------|-------|-------------|
| Wide (1) | 1 | 0 | Wide ball, no runs off bat |
| Wide + 1 run (2) | 2 | 0 | Wide + batsmen ran 1 |
| Wide + 3 runs (4) | 4 | 0 | Wide + batsmen ran 3 |
| No Ball (1) | 1 | 0 | No ball, no runs off bat |
| No Ball + 1 run (2) | 2 | 0 | No ball + 1 run scored |
| No Ball + 4 (5) | 5 | 0 | No ball + boundary (4) |
| No Ball + 6 (7) | 7 | 0 | No ball + six (6) |

**Important:** Wide and No Ball do NOT count as a ball bowled!

---

### 3. **🏃 Byes & Leg Byes** (Ball Counted)
| Button | Runs | Balls | Description |
|--------|------|-------|-------------|
| 1 Bye | 1 | +1 | Ball missed by batsman & keeper, 1 run |
| 2 Byes | 2 | +1 | Ball missed, 2 runs |
| 4 Byes | 4 | +1 | Ball missed, reached boundary |
| 1 Leg Bye | 1 | +1 | Ball hit body (not bat), 1 run |
| 2 Leg Byes | 2 | +1 | Ball hit body, 2 runs |
| 4 Leg Byes | 4 | +1 | Ball hit body, reached boundary |

**Important:** Byes and Leg Byes count as a ball bowled!

---

### 4. **❌ Wickets** (Ball Counted)
| Button | Runs | Wickets | Balls | Description |
|--------|------|---------|-------|-------------|
| Wicket | 0 | +1 | +1 | Bowled, caught, LBW, stumped |
| Run Out (0 runs) | 0 | +1 | +1 | Run out, no runs completed |
| Run Out (1 run) | 1 | +1 | +1 | Run out, 1 run completed |
| Run Out (2 runs) | 2 | +1 | +1 | Run out, 2 runs completed |

**Important:** All wickets count as a ball bowled!

---

### 5. **🔄 Overthrows** (Ball Counted)
| Button | Runs | Balls | Description |
|--------|------|-------|-------------|
| 1 + 4 Overthrow (5) | 5 | +1 | Ran 1, then ball went to boundary (4) |
| 2 + 4 Overthrow (6) | 6 | +1 | Ran 2, then ball went to boundary (4) |
| 3 + 4 Overthrow (7) | 7 | +1 | Ran 3, then ball went to boundary (4) |

**Important:** Overthrows count as a single ball!

---

## 📊 Cricket Scoring Summary

### **Ball Counted (+1 to balls):**
✅ Regular deliveries (Dot, 1, 2, 3, 4, 6)
✅ Byes & Leg Byes
✅ Wickets (all types)
✅ Run Outs
✅ Overthrows

### **NO Ball Counted (0 to balls):**
❌ Wide
❌ No Ball

---

## 🎯 Examples:

### Example 1: Wide with runs
- Bowler bowls wide
- Batsmen run 1
- **Click:** "Wide + 1 run (2)"
- **Result:** 2 runs, 0 balls (over stays at same ball)

### Example 2: No Ball boundary
- Bowler bowls no ball
- Batsman hits 4
- **Click:** "No Ball + 4 (5)"
- **Result:** 5 runs, 0 balls

### Example 3: Run Out
- Batsmen attempt 2 runs
- Run out on 2nd run
- **Click:** "Run Out (1 run)"
- **Result:** 1 run, 1 wicket, 1 ball

### Example 4: Overthrow
- Batsman hits and runs 2
- Fielder throws, goes to boundary
- **Click:** "2 + 4 Overthrow (6)"
- **Result:** 6 runs, 1 ball

### Example 5: Leg Bye boundary
- Ball hits batsman's pad
- Runs to boundary
- **Click:** "4 Leg Byes"
- **Result:** 4 runs, 1 ball

## ✏️ Manual Editing

If you make a mistake:
1. **Click on the score** (e.g., "99/3 (12.4 ov)")
2. **Edit directly** - change to "100/3 (13.0 ov)"
3. **Click away** - auto-saves!

---

## 🔄 Switch Innings

When first innings ends:
1. Click **"🔄 Switch Innings"**
2. Now Team B bats
3. Team A's buttons disappear (they're bowling)
4. Team B gets all scoring buttons
